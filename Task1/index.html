Пример 01

Якоб Нильсон в своей книге «Веб-дизайн» даёт такую рекомендацию: «наиболее важные сведения следует помещать в верхней части страницы».

В самом деле, пользователи часто не читают, а пролистывают страницы сайта. Поэтому они видят только то, что расположено наверху, без вертикальной прокрутки.

Там же Якоб Нильсон пишет:

Нередко при беглом ознакомлении пользователи читают только первое предложение каждого из абзацев. Это обуславливает важность использования тематических предложений, а также соблюдать правило «один абзац — одна законченная мысль ».

Пример 2

Объект — это единая конструкция, содержащая в себе описания данных и функций или, в терминологии JavaScript, свойств и методов.

Программист может создать экземпляр объекта при помощи команды new. Созданный экземпляр будет обладать свойствами и методами объекта, от которого он был создан. 

        Создадим экземпляр now от встроенного объекта Date и вычислим с 
        помощью него число дней, прошедших с начала года: 

        
            // Текущая дата и время.
            var now = new Date();

            // Начало текущего года.
            var begin = new Date(now.getYear(),0,1);

            // Число миллисекунд от начала года.
            var d = now.getTime() - begin.getTime();

            // Число миллисекунд в дне.
            var msPerDay = 24*60*60*1000;

            // Поделим на количество миллисекунд в сутках.
            d /= msPerDay;

            // Покажем результат
            alert("Прошло" + Math.floor(d) + " дней с начала года");

Пример 05

Опустите лишние слова

Избавьтесь от половины слов на каждой странице, затем уберите ещё половину из того, что осталось

Треьтй закон Круга

Из пяти или шести вещей, которые мне довелось узнать в школе, одна запомнилась мне больше других и оказалась самой полезной. Это семнадцатое правило из «Основы стиля»; Э. Б. Уайта:

17. Опустите лишние слова. Хорошее письмо всегда кратко Предложение не должно содержать ненужных слов, а абзац не должен содержать ненужных предложений по той же самой причине, по которой на холсте не должно быть ненужных линий, а в машине — ненужных деталей.

Глядя на большинство веб-страниц, я поражаюсь тому, что большая часть слова на них занимает место, потому что вряд ли кто будет эти слова читать.

Знаки &laquo;&lt;&raquo; и &laquo; &gt;&raquo; служат для обрамления тегов, поэтому для показа на экране их приходится кодировать.

Ниже приводятся четыре примера использования неразрывного пробела (симвоал с кодом &nbsp;).

Пример 1. Между инициалами и фамилией: В. А. Кук (В.&nbsp;А.&nbsp;Кук)
Пример 2. Между знаками номера и числом, относящимся к нему: школа № 133 (школа №&nbsp;133)
Пример 3. В многословных сокращениях: т. д. (т.& nbsp;д.)
Пример 4. Между числом и единицей измерения, относящейся к нему: 2007 год (2007&nbsp;год)
